# PyQt5 Calculator 🧮

A simple calculator application built using **Python and PyQt5** with a graphical user interface (GUI).

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear and reset operations
- User-friendly graphical interface
- Button-based input

## 🛠️ Technologies Used

- Python
- PyQt5
- Object-Oriented Programming (OOP)

## 📂 Project Structure

PyQt5-calculator/
│
└── calculator.py

▶️ How to Run
1. Install Python
Make sure Python is installed on your computer.

3. Install PyQt5
pip install PyQt5

5. Run the calculator
python calculator.py

🎯 Purpose
This project was created to practice Python, PyQt5 GUI development, and object-oriented programming.
